Gestión del sitio

Ofertas, portada y contacto. Cada cambio se publica en el sitio en uno o dos minutos.

Cómo sacar la clave
  1. Entrá a GitHub · Fine-grained token con la cuenta del sitio.
  2. En Repository access elegí Only select repositories y marcá jimenavidal.
  3. En Permissions → Contents elegí Read and write.
  4. Generala, copiala y pegala acá.

Esa clave solo sirve para este sitio. Si se pierde, se borra en GitHub y se saca otra.
